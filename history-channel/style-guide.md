# Style guide

Using the same look, voice and format every time makes the channel recognisable.

## Visual style line

Every Flow scene prompt in the packs already ends with this line. Use it for any new prompts too:

```
Stylized cinematic 3D animation with painterly textures, warm golden lighting, rich earthy colors, soft depth of field, slow smooth camera movement, vertical 9:16 frame. No text, no letters, no subtitles, no logos. Ambient sound only, no dialogue, no music.
```

Why each part is there:
- **"No text…"**: AI video writes gibberish letters, so captions are added in CapCut instead.
- **"Ambient sound only, no dialogue, no music"**: Flow can add sound, but narration and music are added in the edit, so the voice stays the same across all clips.

## Video format (60–70 seconds)

| Part | Time | What happens |
|---|---|---|
| Hook | 0–3 s | A surprising claim or question. The viewer decides here whether to stay |
| Story | 3–55 s | 5–6 quick beats, one per clip |
| Twist / payoff | 55–65 s | The surprising ending or "real truth" |
| Call to action | last 2 s | "Follow for more stories history forgot." |

Keep it **over 60 seconds**, because TikTok only pays for videos longer than 1 minute.

## Narration voice

- Calm, slightly mysterious storyteller. Not shouting, not robotic.
- Use one voice for every video. In AI Studio, write down the voice name you pick.
- Style instruction to paste above the script in AI Studio:
  `Read this like a calm, captivating documentary storyteller. Slight pause after the first sentence. Warm, clear, medium pace.`

## Captions (CapCut)

- Auto captions, **bold white text with a black outline**, 2–4 words at a time, centred in the lower third.
- Highlight the key word in each line in **gold (#F5B83D)**.

## Music

- Soft cinematic or ambient track from CapCut's library, **volume around 15–20%** so the narration is clear.

## Hashtags (base set, add 2–3 topic tags per video)

```
#history #historyfacts #storytime #ancienthistory #didyouknow #historybuff
```
