# Animated History & Stories Channel

A faceless channel that tells true history stories as short animated videos.
Visuals are made in **Google Flow**, narration in **Google AI Studio** (or your own voice), and editing in **CapCut**.
One video is posted to **YouTube Shorts, Instagram Reels, TikTok and Facebook**.

Check that the handle is free on all four platforms before you choose.

## Weekly workflow (about 1–2 hours per video at first, faster later)

1. **Open the next prompt pack** in `week-XX/`.
2. **Characters (Gemini app):** if the pack has a *character image prompt*, generate it once in Gemini, then save the best image.
3. **Clips (Google Flow):**
   - Set the aspect ratio to **9:16 (portrait)**. If that option isn't there, use 16:9 and crop in CapCut.
   - For scenes with a character, use **Ingredients to Video** and add the saved character image.
   - Paste scene prompts 1–8, one per clip. Regenerate any clip that glitches (faces, hands, text).
   - Download all 8 clips.
4. **Narration:** paste the script into **Google AI Studio → Generate speech** (free in the browser, no API key needed), pick one voice and **always use the same voice**. Download the audio. Recording your own voice is even better, because real voices keep viewers watching longer.
5. **Edit (CapCut):** clips in order → add narration → trim clips to match → **Auto captions** → soft background music (CapCut's library) → export 1080×1920. If the narration is shorter than 60 seconds, choose a slower pace in AI Studio or hold the most striking clips a little longer.
6. **Post:** use the title, description and hashtags from the pack. Upload the week in one sitting and **schedule** each day.

## Posting plan

- **Month 1:** 1 Short per day (7 packs per week).
- **Month 2+:** keep daily Shorts and add **one long video per week** (8–12 minutes), which earns far more ad money. Long videos can be built by expanding the best-performing Shorts.
- Best time to post: test **6–8 pm Sri Lanka time** (morning in the US and UK), then follow your analytics.

## Rules

- **Facts first.** Every script is based on well-known, documented history. If a comment points out an error, check it and pin a correction.
- **AI labels.** On YouTube, tick *"Altered or synthetic content"* if a scene could be mistaken for real footage. Stylised animation usually doesn't need it. Instagram and TikTok may add an AI label automatically, which is fine.
- **No real people's faces** from photos, no logos, no famous film or cartoon characters.
- **Reuse music only from the platform's own library** (CapCut, YouTube Audio Library), never from other songs.
